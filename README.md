# InkCast

A simple whiteboard video recorder for Android tablets with a stylus (built for the Samsung Galaxy Tab S9 and S Pen), similar to Vittle on the iPad.

- Write with the S Pen (pressure-sensitive); fingers pan and pinch-zoom
- Import photos and PDFs (each PDF page becomes a page)
- Record the board and your voice as an MP4 video
- Save all pages as one PDF

**Use it:** open https://jlgagnon-glitch.github.io/InkCast/ in Chrome on the tablet, then ⋮ → Add to Home screen.
